# GTA HDR 导出复测 · M3 Pro 与 M6

M3 Pro 为 11 核 CPU、14 核 GPU、18 GiB 内存，运行 macOS 26.6.2，测试时接入电源。M6 运行 macOS 27.2.1。两次用相同的 GTA 片段和处理代码，分别在各自系统上离线导出。

| 路径 | 片段时长 | M3 Pro 用时 / 吞吐 | M6 用时 / 吞吐 | M3 Pro 帧组 P50/P95 | M6 帧组 P50/P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1080p 放大＋补帧 | 29.63 s | 56.16 s / 31.62 fps | 23.74 s / 74.81 fps | 54.64/69.11 ms | 25.83/29.62 ms |
| 原生 4K 补帧 | 65.87 s | 289.48 s / 13.64 fps | 150.50 s / 26.23 fps | 146.20/159.34 ms | 74.78/91.81 ms |

每组包含对应一张 29.97 fps 输入帧的处理，实时预算为 33.37 ms。导出吞吐包括解码、GPU 处理、编码和视频文件收尾。以上是各一轮离线测量，未采集游戏的端到端延时与整机功耗。

## M3 Pro 逐项记录

- 1080p 放大＋补帧，GTA 文件时间戳 `20261121141655`。产出 1,776 帧，含 887 张生成帧。单独补帧 P50/P95 为 39.52/50.37 ms，进程平均 CPU 为 49.1%，峰值 RSS 为 86.2 MiB。
- 原生 4K 补帧，GTA 文件时间戳 `20261123002320`。产出 3,948 帧，含 1,959 张生成帧。单独补帧 P50/P95 为 136.79/149.18 ms，进程平均 CPU 为 46.0%，峰值 RSS 为 133.7 MiB。

两条 29.97 fps 源片和两条 4K 59.94 fps 成片均通过 HEVC Main 10、PQ/BT.2020、帧数和时间戳回读校验，输出 AAC 数据与各自原录像逐字节一致。

本轮把批处理工具和两条素材从 Mac mini 同步到目标机。处理代码与 M6 批次相同，M3 Pro 使用以 macOS 26.0 为最低版本的 arm64 构建。执行命令为 `/usr/bin/caffeinate -i /bin/bash ~/Veyra-HDR-Benchmarks/2026-11-24-m3-pro/tools/run-gta.sh`。
